# ============================================================================
#  ARGO SÖZLÜĞÜ  (GTA / ABD sokak dili → çeviri modelinin anlayacağı düz İngilizce)
# ============================================================================
#  Bu dosyadaki kurallar çeviriye gitmeden ÖNCE İngilizce metne uygulanır.
#  Ekranda gösterilen İngilizce değişmez; sadece Türkçe çeviri etkilenir.
#  Geliştirmede (npm run dev) kaydettiğiniz an geçerli olur; canlıda git push +
#  Coolify yeniden dağıtımı gerekir (dosya uygulamanın içine gömülür).
#
#  İki tür kural var:
#    ifade = yerine            → tam kelime/ifade eşleşir, büyük/küçük harf fark etmez
#    re: kalıp => yerine       → düzenli ifade (regex), dosyadaki sırayla ve ÖNCE uygulanır
#                                (grup referansı \1 veya $1 yazılabilir)
#                                (yerine gelen metindeki boşluklar önemliyse "..." içine yazın)
#
#  Bir kural yanlış sonuç veriyorsa başına # koyup kapatın.
#  Uzun ifadeler kısa olanlardan önce uygulanır ("my nigga", "nigga"dan önce).
#
#  NOT: Birden fazla anlamı olan kelimeler (ride, jack, score, piece, bands,
#  crack, blow, ice, set, cop...) bilerek TEK BAŞINA eklenmedi; sadece anlamı
#  kesin olan kalıplar içinde geçiyorlar ("my ride", "ten grand" gibi).
# ============================================================================


# ---------------------------------------------------------------------------
#  1) YAZIM KISALTMALARI (kalıp kuralları, en önce uygulanır)
# ---------------------------------------------------------------------------
# g düşürme + bitişik yazım: fuckin'dead → fucking dead
re: \b([A-Za-z]{2,})in'(?=[A-Za-z]) => "\1ing "
# g düşürme: happenin' → happening, nothin' → nothing, fuckin' → fucking
re: \b([A-Za-z]{2,})in'(?=\W|$) => \1ing
# "-ass" sıfat eki, arkasından bir isim geliyorsa: "yee-yee ass haircut" → "yee-yee haircut"
re: \b(stupid|dumb|punk|bitch|broke|lazy|crazy|cheap|weak|soft|scary|fake|sorry|yee-yee|bougie|nosy|silly|lame|tired|ugly|bad|big|little|old)[- ]ass (?!(?:all|and|the|for|out|off|over|down|back|here|there|now|again|too|in|on|up|to|is|was)\b)(?=[A-Za-z]{3,}) => "\1 "
# para miktarları: "ten grand", "5 racks", "a couple bands" → "... thousand dollars"
re: \b(\d+|one|two|three|four|five|six|seven|eight|nine|ten|twenty|thirty|fifty|hundred|couple|few|a couple|a few)\s+(?:grand|racks|bands|stacks|G's|Gs|K)\b => \1 thousand dollars
# bitişik 'em: "took'em" → "took them"
re: \b([A-Za-z]+)'em\b => "\1 them"
# "dope" sıfat olarak (= harika): "that's dope", "so dope" → great
re: \b(is|so|pretty|real|hella|that's|that is|was|looks|sounds|mad)\s+dope\b => \1 great
# "yo'" (your anlamında): "yo' bitch" → "your bitch"
re: \byo'(?=[a-z]) => "your "
re: \byo'(?=\s|$) => your
